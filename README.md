# Hi, I'm Sharad 👋

Solo indie hacker building small, sharp tools — mostly AI-assisted, mostly in public.

I'm not here pretending I've figured it all out. I build things, ship them, break them, and learn out loud. This is where that work lives.

## What I'm building

- **[synop](https://github.com/sharadvc/synop)** — Turn hour-long YouTube videos into short, high-signal summaries. Built with Next.js + Prisma.
- **[pingbeacon](https://github.com/sharadvc/pingbeacon)** — Free, open-source uptime monitoring with status pages and alerts. Built with Next.js + Supabase.
- **[XReplyGPT](https://github.com/sharadvc/XReplyGPT)** — A small Chrome extension that drafts X/Twitter replies.

## How I work

I build *with* agents — pairing with AI tooling to move faster and ship more than I could alone. Still learning the craft, still figuring out what "good" looks like, and trying to be honest about both.
